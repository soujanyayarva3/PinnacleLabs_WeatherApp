# PinnacleLabs_WeatherApp
Weather App
Simple Weather Application using HTML, CSS, and JavaScript

Overview
This project is a weather web application that shows real-time weather information of any city using API.

Objective
To build a dynamic weather application using frontend technologies and API integration.

Features
Search weather by city name
Displays temperature, humidity, and weather condition
Real-time weather data using API
Clean and responsive UI

Technologies Used
HTML
CSS
JavaScript
OpenWeather API

Project Workflow
Create UI using HTML
Style layout using CSS
Fetch weather data using API in JavaScript
Display weather details dynamically
Handle user input for city search

Result
The application successfully displays real-time weather information for searched cities.
